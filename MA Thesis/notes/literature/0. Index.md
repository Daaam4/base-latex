## Papers

### 1. [[llm-system-modeling-current-state|Using Large Language Models for System Modeling: Current State and Future Implications]]

A structured literature review of 20 publications on LLMs applied to MBSE tasks (creation, analysis, modification, reformulation). Proposes a modular prompting framework for SysML v1→v2 translation and discusses the emerging role of the Model Context Protocol (MCP) for richer engineering context.

**Key themes:** Literature review · SysML v1→v2 · Prompt engineering · MCP · Evaluation criteria  
**Tags:** #LLM #MBSE #SysMLv2 #PromptEngineering #MCP #LiteratureReview

---

### 2. [[generating-sysmlv2-from-nl-requirements|Generating SysML v2 Models from Natural Language Requirements Using Large Language Models]]

Presents a structured four-component prompting approach (role + ontology + few-shot examples + requirements) to generate syntactically valid, semantically correct SysML v2 models from natural language. Evaluated on an automotive electric window opener use case with precision/recall/F1 and syntax metrics.

**Key themes:** NL-to-SysML · Structured prompting · Ontology · Few-shot · Automotive  
**Tags:** #LLM #MBSE #SysMLv2 #NaturalLanguage #PromptEngineering #Automotive #Requirements

---

### 3. [[mitigating-hallucinations-sysmlv2-kg|Mitigating Hallucinations in SysML v2 Generation Using LLMs and a Tri-Layered Knowledge Graph Reasoning Framework]]

Addresses LLM hallucinations in SysML v2 generation via a three-layer KG architecture: (1) SysML characterisation patterns, (2) domain-specific constructs, (3) system-specific KG auto-generated from requirements. Evaluated in a satellite systems engineering case study.

**Key themes:** Hallucination mitigation · Tri-layer KG · Structural validity · Semantic fidelity · Satellite  
**Tags:** #LLM #MBSE #SysMLv2 #KnowledgeGraph #Hallucinations #RAG #Aerospace #Automotive

---

### 4. [[sysforge-knowledge-augmented-conversational-agents|Knowledge-Augmented Conversational Agents for Dependency-Aware SysML v2 Model Generation and Refinement]]

Introduces **SysForge** — a multi-agent framework with a Conversational Agent, Context Synthesizer, Designer Agent, and Validator Agent. Uses dependency-aware KG retrieval and iterative refinement to generate consistent SysML v2 code. Outperforms standard LLM and semantic RAG baselines on Pass@1 and BLEU.

**Key themes:** SysForge · Multi-agent · Dependency-aware RAG · Iterative refinement · Evaluation  
**Tags:** #LLM #MBSE #SysMLv2 #KnowledgeGraph #RAG #ConversationalAgent #SysForge #MultiAgent

---

### 5. [[enabling-humans-ai-retrieve-mbse|Enabling Humans and AI Systems to Retrieve Information from System Architectures in Model-Based Systems Engineering]]

Builds a GraphRAG-based multi-agent system (Supervisor Agent + Graph Query Agent) on top of a Neo4j knowledge graph parsed from SysML v2 textual notation. Uses RFLP methodology for graph schema. Evaluated on a battery electric vehicle reference model; Gemini-2.5-flash-preview achieves 93% overall accuracy.

**Key themes:** GraphRAG · RFLP · Neo4j · Multi-agent · Information retrieval · SysML v2 parser  
**Tags:** #LLM #MBSE #SysMLv2 #GraphRAG #KnowledgeGraph #MultiAgent #RFLP #InformationRetrieval
