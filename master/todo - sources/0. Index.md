## Source-type policy (→ exposé section "Überlegungen zu Quellenarten")

The topic is ~2 years old (DeHart, July 2024 → today), and its state of the art exists **unevenly across venue types**. A purely peer-reviewed corpus would misrepresent it: the only controlled SysML v2 agent-tooling experiment is an SEI blog post, and every deployed MCP server for SysML v2 exists only as a repository. Grey literature is therefore included **deliberately and with an explicit weighting rule**:

| Type | Evidential role | Weight |
|---|---|---|
| **1 Scientific** | Claims about method, capability, and gaps | Primary. Carries all argumentative load. |
| **2 Blogs** | Industrial adoption, motivation, documented tool facts; one controlled experiment (SEI) | Supporting. Performance claims cited *as claims*, marked unvalidated. |
| **3 Repos** | The state of the art of *artifacts* — what exists, what it does, what it lacks | Primary **for artifact claims only**, and only when verified by inspection (+ commit/version + access date). |

**Time window:** 2024–2026, with emphasis on **2025–2026** (SysML v2 textual syntax + REST API became formal OMG standards in September 2025; MCP appeared late 2024). One 2024 paper (DeHart) as the origin of the idea; older MBSE/SysML foundations only where structurally necessary.
**Venues represented:** INCOSE International Symposium (3), IEEE ISSE (2), MODELS-C, DASC, Proceedings of the Design Society (DESIGN), PAAMS (Springer LNAI), *Systems Engineering* (Wiley), *Systems* (MDPI), CCSSTA, arXiv cs.SE/cs.AI/cs.CE (7 preprints, all 2025–26), OMG standards. (Bouamra/SysTemp moved from arXiv preprint to this peer-reviewed PAAMS 2025 entry, 19.09.2026.)
**Preprint policy:** arXiv preprints are used where the peer-reviewed literature has not caught up (agent benchmarks, MCP); each is marked as preprint in the list and will be replaced by the published version if one appears before submission.

## 2 — Blogs & grey literature

### [dempsey2026nativeai](../bib/summaries/dempsey2026nativeai-summary.md) 🔴 **[TOP 3]**
Dempsey (SEI/CMU), 2 Sep 2026. Controlled 3-arm SysML v2 benchmark (baseline / CLI-only validation loop / full MCP-knowledge-retrieval + skills tooling), 8 tasks x 2 scales, Claude Opus 4.6. Validation loop → 0 syntax errors but pattern score barely moves (78.3→71.7); curated knowledge+skills → 71.7→94.1. Worked 4-drone example: 0 validator errors yet separation/lost-link parameters silently drift from the prompt — syntactic validity ≠ correctness, in their own words. **Closest evaluated work**; file-based (Syside LSP + retrieval-only MCP server), so this thesis differentiates on the industrial-tool / live-model axis.
**Bib:** `dempsey2026nativeai` · Type 2 blog, but full text captured/read — filed as a summary in `bib/summaries/` (like a Type 1 source) rather than left in `todo - sources/`. Archived page: `bib/papers/dempsey2026nativeai.html`.

## Working rules
1. Every new source gets a summary file in the right type folder **and** a row here.
2. Summaries state **topic · method · relevance** — the same triple the exposé's annotated list needs.
3. **Never invent metadata.** Unverified fields stay `TODO` in `quellen.bib` until checked against Crossref / arXiv / the PDF.
4. Numbers quoted from a paper must be traceable to abstract or full text; abstract-only sources say so in their summary file (Bazzal, Ahlbrecht figures, Al-Shami, DeHart).
