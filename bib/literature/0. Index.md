## Source-type policy (→ exposé section "Überlegungen zu Quellenarten")

The topic is ~18 months old, and its state of the art exists **unevenly across venue types**. A purely peer-reviewed corpus would systematically misrepresent it: the only controlled SysML v2 agent-tooling experiment is an SEI blog post, and every existing MCP server for SysML v2 exists only as a repository. Grey literature is therefore included **deliberately and with an explicit weighting rule**:

| Type | Evidential role | Weight |
|---|---|---|
| **1 Scientific** | Claims about method, capability, and gaps | Primary. Carries all argumentative load. |
| **2 Blogs** | Industrial adoption, motivation, documented tool facts; one controlled experiment (SEI) | Supporting. Performance claims cited *as claims*, marked unvalidated. |
| **3 Repos** | The state of the art of *artifacts* — what exists, what it does, what it lacks | Primary **for artifact claims only**, and only when verified by inspection (+ commit/version + access date). |

**Time window:** 2023–2026, with emphasis on **2025–2026** (SysML v2 textual syntax + REST API became formal OMG standards in September 2025; MCP appeared late 2024). Older MBSE/SysML foundations are cited only where structurally necessary.
**Venues targeted:** INCOSE *Systems Engineering*, MODELS, SysCon, ICSE/MoDRE, INCOSE IS, CSER, arXiv (cs.SE / cs.AI), plus OMG standards documents.

## 1 — Scientific (`1-scientific/`)

### 1. [llm-system-modeling-current-state](1-scientific/llm-system-modeling-current-state.md)
*Using Large Language Models for System Modeling: Current State and Future Implications*
Structured literature review of 20 publications on LLMs for MBSE tasks (creation, analysis, modification, reformulation). Proposes a modular prompting framework for SysML v1→v2 translation and discusses MCP as an emerging mechanism for supplying engineering context.
**Bib:** `llm-system-modeling-review` · ⚠️ metadata `TODO` · **Tags:** #LLM #MBSE #SysMLv2 #PromptEngineering #MCP #LiteratureReview

### 2. [generating-sysmlv2-from-nl-requirements](1-scientific/generating-sysmlv2-from-nl-requirements.md)
Four-component prompting approach (role + ontology + few-shot + requirements) to generate syntactically valid, semantically correct SysML v2 from natural language. Evaluated on an automotive electric-window use case with precision/recall/F1 and syntax metrics.
**Bib:** `nl2sysml` · ⚠️ metadata `TODO` · **Tags:** #NaturalLanguage #PromptEngineering #Automotive #Requirements

### 3. [mitigating-hallucinations-sysmlv2-kg](1-scientific/mitigating-hallucinations-sysmlv2-kg.md)
Tri-layered knowledge-graph framework (SysML patterns / domain constructs / system-specific KG from requirements) to reduce hallucination in SysML v2 generation. Satellite systems-engineering case study.
**Bib:** `kg-hallucination` · ⚠️ metadata `TODO` · **Tags:** #KnowledgeGraph #Hallucinations #RAG #Aerospace

### 4. [sysforge-knowledge-augmented-conversational-agents](1-scientific/sysforge-knowledge-augmented-conversational-agents.md)
**SysForge** — multi-agent framework (Conversational Agent, Context Synthesizer, Designer, Validator) with dependency-aware KG retrieval and iterative refinement. Beats standard LLM and semantic-RAG baselines on Pass@1 and BLEU.
**Bib:** `sysforge` · ⚠️ metadata `TODO` · **Tags:** #MultiAgent #RAG #SysForge

### 5. [enabling-humans-ai-retrieve-mbse](1-scientific/enabling-humans-ai-retrieve-mbse.md)
GraphRAG multi-agent system (Supervisor + Graph Query Agent) over a Neo4j KG parsed from SysML v2 textual notation, schema'd by RFLP. Battery-EV reference model; Gemini-2.5-flash-preview reaches 93 % accuracy.
**Bib:** `graphrag-mbse` · ⚠️ metadata `TODO` · **Tags:** #GraphRAG #Neo4j #RFLP #InformationRetrieval

## Working rules
1. Every new source gets a summary file in the right type folder **and** a row here.
2. Summaries state **topic · method · relevance** (the same triple the exposé's annotated list needs) — write them in that form and the annotated list becomes a copy job.
3. **Never invent metadata.** Unverified fields stay `TODO` in `quellen.bib` until checked against the PDF/DOI.
4. Target for M1: **15–20 sources**, ≥ 10 of them scientific, with the **3 most important marked `[TOP 3]`**.
